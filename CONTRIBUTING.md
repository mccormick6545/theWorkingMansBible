# Contributing

Contributions are welcome. Please open an issue for significant features first.

- Keep code portable across supported Apple platforms where possible.
- Include tests for calculation code and document units and assumptions.
- Do not contribute copied OEM manuals, proprietary service data, or unsourced torque values.
- Third-party content requires license, provenance, attribution, and review.
- Do not commit secrets, personal information, or credentials.
- By contributing, you agree to license your original code contributions under Apache-2.0.
