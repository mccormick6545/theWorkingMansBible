# Working Man's Bible architecture

A universal SwiftUI app for iPhone, iPad, and Mac is planned, using a shared local Swift package.

## Core modules
- Trade and vehicle catalogs, calculators, project tracking.
- Offline SQLite database with optional data synchronization.
- Source citations, licenses, and verification metadata for third-party technical data.
- Native PDF, document, and 3D model viewers.
- Desktop-only CAD/simulation engines integrated through adapters, not shipped as iOS binaries.

## Safety
Calculations must include units and assumptions. Fastener torque requires source, year/model/engine fitment, and tightening instructions. Do not invent specifications or represent geometric estimates as structural designs.
